Transfer

Setup

The current system requires the user to manually write the Grasshopper 3D model data into the MATLAB HabSim file, run the HabSim virtual simulation, and copy the output data back into Grasshopper. This is laborious, time consuming, and prone to human error and typos.

2.Project Aim

Grasshopper
›
File-based bridge
›
MATLAB HabSim

Build a file-based bridge between Grasshopper and HabSim in MATLAB, allowing the transfer and mapping of variables from GH to MATLAB and vice versa, running the HabSim virtual simulation automatically, and notifying the user once the simulation is completed.

4.Key Features

User-friendly GUI

  • File Browser
  • Custom Configuration
  • Change Variables
  • Link/Unlink Variables
  • Grasshopper Internal Application
  • External Application

Fuzzy Matching Algorithm

  • Finds Similarly Spelt Variables
  • Typo Recognition
  • Links Variables with High Confidence
  • Helps Identify Spelling Errors

Transfer History

  • Stores Previous Transfers
  • Old Variables Easily Accessible
  • Restore Previous State
  • Show Dates and Times of Transfer

Notification System

  • Notifies User when Simulation Completed
  • Notifications to Desktop
  • Notifications to Mobile Device

Supports Strings & Arrays

  • Allows for a Variety of Data Types
  • Preloaded Configuration with Several Equivalent Data Structures Between Grasshopper and MATLAB
  • Allows for Custom Data Equivalency Configurator

Export Results (JSON/TXT/CSV)

  • Can Easily Export Data to Any File Type
  • Works for Any Input File
  • Instant Transfer
